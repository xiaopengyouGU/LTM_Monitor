# 示例工程

本目录是**下位机侧**的协议实现与移植示例，全部以 **MIT** 许可发布（见本目录 `LICENSE`）：
可以自由复制、修改并集成到闭源固件，只需保留版权与许可声明。

| 目录 | 说明 |
|---|---|
| `protocol/` | 通讯协议本体（纯 C、无依赖），帧格式、数据类型、CRC16 |
| `STM32/` | STM32F103C8T6 移植示例（UART 收发 + 上位机联调演示） |
| `Renesas/` | 野火 RA6T2 电机开发板移植示例 |
| `BootLoader/` | 串口 IAP（LTM 协议）与 CAN-FD UDS 升级的下位机 BootLoader 示例 |

`STM32/` 与 `Renesas/` 是打包好的完整工程（zip），解压后直接用对应 IDE 打开即可。

上位机本体（本仓库 `src/`）为 GPLv3，与本目录无关。
